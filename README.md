# Caca ao Tesouro - Estrutura de Dados em Java

Projeto desenvolvido como atividade da disciplina de **Estrutura de Dados II**, com o objetivo de aplicar conceitos de grafos de forma prática e interativa.

---

## Objetivo

Simular um jogo de caça ao tesouro onde o usuário navega por diferentes locais (nós) conectados por caminhos (arestas), tomando decisões até encontrar o tesouro ou chegar a um fim de jogo.

Durante a jornada, o jogador coleta letras que formam uma palavra final.

---

## Como funciona o jogo

1. O jogador inicia no nó **"Início"**
2. A cada etapa:
   - O sistema mostra uma dica
   - Exibe possíveis caminhos
3. O jogador escolhe uma opção
4. Pode acontecer:
   - Avançar corretamente
   - Cair em uma armadilha (Game Over)
5. Ao seguir o caminho correto:
   - O jogador coleta letras
6. No final:
   - O jogador deve digitar a palavra formada
   - Se estiver correta → ganha o tesouro
